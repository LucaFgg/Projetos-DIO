# Projetos-DIO
Lista de projetos plataforma DIO curso / Explore o Poder do NotebookLM
*Contexto e Objetivos:
O assunto de interrese escolhido é "Segundo Cérebro: Ayrton Senna e os princípios do automobilismo"
Os principais objetivos são, estudar a trajetória e a mentalidade de Ayrton Senna; identificar princípios de desempenho, preparação, foco, tomada de decisão e estratégia; relacionar esses ensinamentos com situações fora das pistas.
